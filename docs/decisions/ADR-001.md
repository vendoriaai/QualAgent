# ADR-001: ONNX embeddings instead of sentence-transformers

## Status

Accepted (2026-08-18)

## Context

TAD §2 specifies sentence-transformers (`all-MiniLM-L6-v2`) for memory
embeddings. Installing sentence-transformers pulls in PyTorch (~2.5 GB) — a
heavy footprint for a local-first CLI tool, and a long install that conflicts
with the "5-minute quickstart" promise (PRD §6, story 12; README quickstart).

## Options

1. **sentence-transformers (spec-exact).** Same model, torch dependency.
2. **ChromaDB built-in ONNX MiniLM-L6-v2.** Same embedding model served through
   onnxruntime (~50 MB), already a dependency via chromadb. Model weights are
   downloaded once on first use, then cached offline.
3. **No embeddings (stub memory).** Violates FR-9.

## Decision

Option 2: use chromadb's default embedding function (ONNX `all-MiniLM-L6-v2`).
`sentence-transformers` remains an optional pip extra
(`pip install qualagent[sentence-transformers]`) for users who want it; the
embedding backend is configurable via `[memory] embedding_backend`.

## Consequences

- No PyTorch in the default install; offline after the first model download.
- Deviation from TAD §2 stack table, documented here per builder instruction §6.
- Embeddings are numerically equivalent (same MiniLM-L6-v2 model).
